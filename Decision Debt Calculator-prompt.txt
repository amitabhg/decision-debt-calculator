Build a polished single-file web app named “Decision Debt Calculator” that helps students and professionals compare 3 to 5 life options such as MBA, job switch, startup, certification, higher studies, or freelancing.
Think like a senior product designer and frontend engineer. Make the UX feel like a real shipped SaaS tool

Core user problem:
People struggle to choose between important career or business paths because trade-offs are hard to compare clearly. The app should reduce decision anxiety by converting subjective thinking into a weighted comparison system with clear rankings, visual feedback, and plain-language explanations.

Product goal:
Create a decision-support web app that feels premium, modern, and practical. The user enters several options, sets factor weights, scores each option, and instantly sees which path ranks highest under different scenarios.

App type:
Interactive web app / decision dashboard
No backend required
Static HTML/CSS/JS only
All logic client-side
No localStorage/sessionStorage dependency
Responsive for desktop and mobile

Design direction:
Use a clean, credible, high-trust product aesthetic.
Avoid generic AI-looking gradients, glowing blobs, or overdecorated SaaS layouts.
Use neutral surfaces with one restrained accent color.
Use compact web app typography, not oversized landing-page typography.
The app should feel like a serious decision tool for ambitious students and professionals.
Prioritize clarity, confidence, and speed of use.

Brand:
Project name: Decision Debt Calculator
Include a simple custom inline SVG logo that visually suggests balance, trade-offs, or weighted comparison.
Provide light mode and dark mode with a toggle.

Main workflow:
1. User enters a decision title, such as “What should I do next?”
2. User creates 3–5 options, for example MBA, job switch, startup
3. User reviews or edits default criteria
4. User assigns importance weights to criteria
5. User scores each option against each criterion
6. Rankings update instantly
7. User toggles scenario views like Short Term, Growth, and Safety
8. App generates recommendation text explaining why one option leads and what trade-offs exist
9. User can print or export a clean report-style summary view

Default criteria:
- Salary / earning potential
- Learning / skill growth
- Risk
- Time to payoff
- Flexibility
- Passion / personal fit

Let the user:
- Rename criteria
- Add or remove criteria
- Adjust criterion weights with sliders or number inputs
- Add, edit, duplicate, or remove options
- Score each option on a clear fixed scale, preferably 1 to 10
- See totals recalculate in real time

Scoring logic:
- Weighted decision matrix model
- Each option has a score per criterion
- Final weighted score = sum of (criterion weight × option score normalized to scale)
- Show both raw score and weighted contribution if useful
- Rank options from highest to lowest
- Handle ties gracefully
- Clearly indicate top recommendation

Scenario mode:
Include quick scenario toggles that automatically rebalance weights:
- Best for short term
- Best for growth
- Best for safety
- Best for freedom
- Balanced default

Example:
Short term should favor salary and time to payoff
Growth should favor learning and future upside
Safety should favor low risk and stability
Freedom should favor flexibility and passion

Also allow manual weight editing after a scenario is applied.
